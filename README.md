# Fake_news_detector
A machine learning-based Fake News Detector that classifies news articles as real or fake using Natural Language Processing (NLP) techniques.

🔍 Overview
The rise of misinformation highlights the need for automated solutions to detect fake news. This project aims to address that by leveraging NLP and supervised learning to build an effective classifier.

📌 Features
Text preprocessing using NLP techniques

TF-IDF vectorization

Machine learning classification (e.g., Logistic Regression / Naive Bayes)

Real vs Fake prediction on user input

Simple and interactive UI (optional if you built one)

🧠 Tech Stack
Python

Scikit-learn

Pandas, NumPy

NLTK / spaCy (for NLP)

Flask / Streamlit (if deployed as a web app)

🗂️ Dataset
Used the Fake and Real News Dataset from Kaggle.
